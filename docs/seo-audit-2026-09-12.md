# SEO audit — 12 September 2026

## Evidence and limitations

Reviewed the live site, source code, public search results and four agencies’ own pages. Search results are a discovery sample, not a localized ranking report. No connected Search Console or keyword/backlink tool was available: impressions, index coverage, volume, difficulty and traffic are unknown. The public PageSpeed API returned 429 (quota exceeded), so no performance score or field Core Web Vitals result is claimed.

## Findings and implemented changes

| Priority | Before | Applied |
| --- | --- | --- |

| Pass | One active showcase video, static posters, no visible captions. | Preserved. |

## Primary guidance

- [Google SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide): useful content and links; changes can take hours to months, with no first-place guarantee.
- [Google title links](https://developers.google.com/search/docs/appearance/title-link): clear, descriptive titles; displayed titles may differ.
- [Google sitemap guidance](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap): canonical URLs and accurate dates; no indexing guarantee.
- [Google Business Profile eligibility](https://support.google.com/business/answer/13763036): in-person contact requirements and online-only exclusion.

## Verification scope

Release checks cover lint/build, rendered metadata, canonicals, valid JSON-LD, sitemap coverage, unknown-route 404, browser layout and public-domain route checks. They establish technical behavior, not ranking gains.
